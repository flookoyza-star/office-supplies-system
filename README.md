# 📦 ระบบรับ-จ่ายและบริหารสต็อกอุปกรณ์สำนักงานแบบครบวงจร (Office Supplies WebApp)

ระบบ Web Application สำหรับบริหารจัดการอุปกรณ์และพัสดุสำนักงานแบบครบวงจร (กระดาษ, หมึกพิมพ์, ปากกา, แฟ้ม, อุปกรณ์สำนักงาน ฯลฯ) พร้อมระบบขอเบิกพัสดุออนไลน์, ตัดสต็อกอัตโนมัติ, แจ้งเตือนของใกล้หมด, พิมพ์ใบเบิกมาตรฐาน A4 และระบบออกรีพอร์ตวิเคราะห์ส่งออกเป็น Excel (.xlsx)

---

## 🌟 ฟังก์ชันการทำงานหลัก (Key Features)

1. **คลังพัสดุและสต็อกอุปกรณ์ (Inventory & Catalog):**
   - เพิ่ม, แก้ไข, ลบรายการอุปกรณ์สำนักงาน
   - กำหนดรหัสพัสดุ, ชื่อ, หมวดหมู่, หน่วยนับ, ราคาต่อหน่วย, สถานที่จัดเก็บ (ตู้/ชั้น/ลิ้นชัก)
   - กำหนดจุดเตือนสั่งซื้อขั้นต่ำ (Reorder / Min Stock)
   - ระบบคำนวณมูลค่าคงเหลือในคลังตามราคาทุนอัตโนมัติ

2. **ระบบการขอเบิก-จ่ายพัสดุ (Requisitions & Dispensing):**
   - ขอเบิกได้หลายรายการใน 1 ใบเบิก (Multi-item Requisition Slip)
   - ระบุผู้ขอเบิก, แผนก/ฝ่าย, วัตถุประสงค์ในการใช้
   - ระบบตรวจสอบสต็อกคงเหลือแบบเรียลไทม์ ป้องกันการเบิกเกินของที่มีในคลัง
   - ระบบขั้นตอนการอนุมัติ (Status Workflow): `รออนุมัติ/รอเบิก (Pending)` ➔ `อนุมัติ & ตัดสต็อก (Approved)` ➔ `ปฏิเสธ (Rejected)`
   - พิมพ์ใบเบิกพัสดุทางการมาตรฐาน A4 พร้อมช่องลายเซ็น 4 ฝ่าย (ผู้ขอเบิก, หัวหน้างาน/ผู้อนุมัติ, ผู้จ่ายของ, ผู้รับของ)

3. **ระบบรับเข้าพัสดุสู่สต็อก (Stock-In Receiving):**
   - บันทึกการรับเข้าพัสดุพร้อมระบุเลขที่ใบสั่งซื้อ (PO/INV), ผู้จัดจำหน่าย, ผู้ตรวจรับ
   - เพิ่มยอดสต็อกคงเหลืออัตโนมัติและอัปเดตราคาต้นทุน

4. **ระบบออกรายงานและสถิติแบบละเอียด (Comprehensive Reports & Analytics):**
   - **รายงานที่ 1:** สรุปสต็อกคงเหลือและมูลค่ารวมตามหมวดหมู่วัสดุ
   - **รายงานที่ 2:** รายงานการขอเบิก-จ่ายพัสดุ กรองตามช่วงวันที่, แผนก, หรือบุคคล
   - **รายงานที่ 3:** รายงานการรับเข้าพัสดุ แยกตามผู้จัดจำหน่ายและช่วงเวลา
   - **รายงานที่ 4:** รายงานสรุปยอดค่าใช้จ่ายและปริมาณการใช้อุปกรณ์แยกตามแผนก
   - **รายงานที่ 5:** รายงานวัสดุที่ต้องจัดซื้อเพิ่ม (Reorder / Low Stock List) พร้อมคำนวณงบประมาณจัดซื้อโดยประมาณ
   - **Export Excel:** ดาวน์โหลดตารางรายงานทุกประเภทเป็นไฟล์ `.xlsx` (เปิดใน Excel ได้ทันที)
   - **พิมพ์ A4 / PDF:** มีระบบ Print CSS จัดหน้าพิมพ์มาตรฐานโดยไม่ต้องลงโปรแกรมเพิ่ม

5. **แดชบอร์ดสรุปภาพรวม (Dashboard Overview):**
   - KPI Cards: จำนวนรายการทั้งหมด, แจ้งเตือนของใกล้หมด/หมดสต็อก, ใบเบิกรอจ่าย, มูลค่าสต็อกรวม
   - กราฟแท่งเปรียบเทียบยอดเบิกของแต่ละแผนก (Department Usage)
   - กราฟโดนัทสัดส่วนมูลค่าสต็อกตามหมวดหมู่ (Category Distribution)

6. **ระบบตั้งค่า & สำรองข้อมูล (Settings & Backup):**
   - ตั้งชื่อองค์กร, ที่อยู่สำนักงาน, เบอร์โทร สำหรับแสดงบนหัวบิลและใบเบิก
   - จัดการหมวดหมู่อุปกรณ์ (เพิ่ม/ลบหมวดหมู่)
   - จัดการแผนก/ฝ่ายในสำนักงาน
   - ระบบสำรองข้อมูลทั้งหมด (Backup JSON) และกู้คืนข้อมูล (Restore JSON)

## 🚀 วิธีเปิดใช้งานบนเครื่อง และแชร์ให้ทุกคนในสำนักงานใช้ร่วมกัน (Local / LAN Setup)

### ขั้นตอนที่ 1: ติดตั้งโปรแกรมที่จำเป็น (ถ้ายังไม่มี)
- ติดตั้ง **Node.js** (ดาวน์โหลดฟรีที่ [nodejs.org](https://nodejs.org) - แนะนำเวอร์ชัน LTS)

### ขั้นตอนที่ 2: ติดตั้งและเปิดรันระบบ
1. เปิดโปรแกรม **Terminal** หรือ **PowerShell** แล้วเข้าไปที่โฟลเดอร์ของโปรเจกต์:
   ```bash
   cd d:\Users\chalit\.gemini\antigravity\scratch\office-supplies-system
   ```
2. สั่งติดตั้งโมดูล:
   ```bash
   npm install
   ```
3. สั่งเริ่มระบบ:
   ```bash
   npm start
   ```
4. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:3000
   ```

### 💡 วิธีให้พนักงานคนอื่นในออฟฟิศเปิดใช้งานผ่าน Wi-Fi วงเดียวกัน
1. ตรวจสอบ IP Address ของเครื่องคอมพิวเตอร์ของคุณ โดยเปิด Command Prompt พิมพ์:
   ```cmd
   ipconfig
   ```
   (ดูค่า `IPv4 Address` เช่น `192.168.1.120`)
2. ให้เพื่อนร่วมงานในสำนักงานเปิดเบราว์เซอร์บนคอมพิวเตอร์ มือถือ หรือแท็บเล็ต แล้วพิมพ์:
   ```
   http://192.168.1.120:3000
   ```
   ทุกคนจะสามารถเข้าใช้งาน ส่งใบเบิก และตรวจสอบสต็อกร่วมกันได้ทันที!

## 🌐 วิธีนำขึ้นเป็น Web Application บนอินเทอร์เน็ต (ใช้งานจริง 24 ชม. ฟรี)

คุณสามารถนำเว็บแอปนี้ขึ้น Cloud เพื่อให้ทุกคนเบิกของหรือดูสต็อกได้จากทุกที่ ผ่านอินเทอร์เน็ตบนมือถือและคอมพิวเตอร์ โดยมีบริการฟรีแนะนำดังนี้:

### ทางเลือกที่ 1: Deploy บน Render.com (แนะนำที่สุด - ฟรีและง่ายมาก)

1. **สร้างบัญชีบน GitHub และ Render:**
   - สมัครบัญชีที่ [github.com](https://github.com)
   - สมัครบัญชีที่ [render.com](https://render.com) (เข้าสู่ระบบด้วยบัญชี GitHub)

2. **นำโค้ดขึ้น GitHub:**
   - ในโฟลเดอร์โปรเจกต์ รันคำสั่ง:
     ```bash
     git init
     git add .
     git commit -m "Initial commit for office supplies system"
     git branch -M main
     git remote add origin https://github.com/<YOUR_USER>/office-supplies-system.git
     git push -u origin main
     ```

3. **สร้าง Web Service บน Render:**
   - กดปุ่ม **New +** ➔ เลือก **Web Service**
   - เลือก Repository ที่เพิ่งอัปโหลดบน GitHub
   - ตั้งค่าดังนี้:
     - **Name:** `my-office-inventory` (ตามต้องการ)
     - **Region:** `Singapore` (ใกล้ไทย ตอบสนองเร็วที่สุด)
     - **Branch:** `main`
     - **Runtime:** `Node`
     - **Build Command:** `npm install`
     - **Start Command:** `node server.js`
     - **Instance Type:** `Free`
   - กดปุ่ม **Create Web Service**

4. **พร้อมใช้งาน:**
   - Render จะสร้าง URL ให้คุณ เช่น `https://my-office-inventory.onrender.com`
   - สามารถแชร์ลิงก์นี้ให้พนักงานในบริษัทเปิดใช้งานได้ทันที!

> **💡 เคล็ดลับเพิ่มเติม:** หากต้องการเก็บข้อมูลบนฐานข้อมูล Cloud ตลอดไป ให้สร้าง **PostgreSQL Database** ฟรีบน Supabase (supabase.com) หรือ Neon (neon.tech) แล้วนำ Connection String มาใส่ในช่อง Environment Variable ของ Render ชื่อ `DATABASE_URL` ระบบจะสลับไปบันทึกบนคลาวด์ให้อัตโนมัติ!
